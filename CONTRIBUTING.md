# Contributing to Research Hub AI

Researchers and developers are welcome. The original code is released under Apache-2.0. Contributed code should be your own or licensed compatibly. Contributions may be used under the project's licence; retain required notices. Teaching content must have appropriate attribution and redistribution rights.

1. Open an issue describing the learner/researcher problem.
2. Work on a branch or fork. Keep the changes small and accessible.
3. Include tests for functional changes; run `npm test` (no dependency installation required).
4. Explain privacy, offline, backup and accessibility impacts.
5. Submit a pull request for maintainer review. Never commit actual human participant data, private files, credentials or API tokens.

No contributor receives direct write access to production or official releases by default. Bug reports and proposed changes are welcome regardless of experience. Forks are permitted by the Apache licence, including commercial forks; the official app remains free.
